# Extension v0.2.8

## 변경 사항

- GitHub App으로 선택한 저장소에 프로그래머스 정답 풀이와 문제 설명을 기록합니다. 저장소의 기본 브랜치를 사용하며, 기록 경로는 선택 입력입니다.
- 최근 풀이의 커밋 링크와 실패 기록 재시도 기능을 확장 프로그램에서 확인할 수 있습니다.
- C 언어 제출 값 인식, 빈칸 채우기 문제의 코드 수집, 문제 레벨 정보 수집을 개선했습니다.
- 저장소 설정을 저장하는 동안 진행 상태를 표시하고 중복 요청을 막습니다.
- 배지 자동 동기화와 GitHub 풀이 기록의 실패 상태를 각각 안내합니다.

## 업데이트 안내

- 프로그래머스 문제 페이지의 풀이 코드를 읽기 위해 `school.programmers.co.kr` 접근 권한이 추가되었습니다.
- 이전 버전에서 `unknown` 레벨 경로에 저장된 파일은 자동으로 이동하지 않습니다.
- Chrome Web Store 게시 요청 후 심사를 통과해야 사용자에게 업데이트가 배포됩니다.
