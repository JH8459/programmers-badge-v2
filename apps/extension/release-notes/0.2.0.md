# Extension v0.2.0

## 변경 사항

- 선택한 GitHub 저장소를 연결하면 Programmers 정답 제출 후 문제 README와 언어별 풀이 코드를 기록합니다.
- 풀이 경로는 `프로그래머스/<레벨>/<문제번호>-<정규화된-문제명>/` 형식이며, 같은 언어의 코드가 바뀌면 덮어쓰고 내용이 같으면 커밋을 건너뜁니다.
- 저장 실패한 풀이는 확장 프로그램에서 다시 시도할 수 있습니다.
- Programmers 문제 페이지에서 문제 정보와 편집기 코드를 읽기 위해 `school.programmers.co.kr` 사이트 접근 권한을 사용합니다.

## 배포 메모

- 확장 프로그램의 GitHub 연결 기능은 API 서버의 GitHub App 설정이 필요합니다.
- Chrome Web Store 자동 게시 workflow는 ZIP package upload와 publish 요청 제출을 진행합니다. Chrome Web Store 반영은 workflow 성공 직후가 아니라 Store review 승인 후 완료됩니다.
